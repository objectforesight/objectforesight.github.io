# ObjectForesight — project page

Source for the project page of **ObjectForesight: Predicting Future 3D Object Trajectories from Human Videos**.

- **Live site:** https://objectforesight.github.io
- **Paper:** https://arxiv.org/abs/2601.05237

The page is a single static `index.html` and links out to the code, dataset, and model releases. Template inspired by [HandsOnVLM](https://www.chenbao.tech/handsonvlm/) and [Nerfies](https://nerfies.github.io/).
